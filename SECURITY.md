# Security and safety policy

- **No personal data of students** (names, photos, marks, contact details) in any public repository, issue, PR or practice repo. Use pseudonyms such as `student-07`.
- **No secrets.** Never commit passwords, tokens or keys. Practice repos contain only fake placeholders.
- **Classroom organisations are private** and managed by the teacher. Learners under 13 do not create accounts on GitHub (its terms require age 13+). Grade 8 is local-only.
- Report a vulnerability or safety concern with a private security advisory on the repository, or email rcgiri.physics@gmail.com.
