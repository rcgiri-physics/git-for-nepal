# Code of Conduct

This project is used by children as young as 12 and by their teachers. Be kind, be patient, and assume good faith.

## Expected
- Welcome beginners. "I don't understand" is always a good question.
- Review the work, not the person. Explain *why* when you ask for a change.
- Use respectful language in Nepali and English.
- Credit other people's work.

## Not acceptable
- Harassment, insults, discrimination (caste, ethnicity, gender, religion, disability, language, region).
- Sharing personal information about students: names, photos, real marks, contact details.
- Spam pull requests (for example, changes made only to count toward an event).
- Pushing students to contact strangers or join unvetted external projects.

## Student-friendly contributions
Pull requests from learners carry the `student-friendly` label. Reviewers give extra-gentle feedback and always explain how to fix a problem.

## Enforcement
Maintainers may edit, hide or remove content and block accounts. Report problems to rcgiri.physics@gmail.com or by opening a private security advisory on the repository.
