# कक्षा १० · Fork, clone र branch फरक

> ड्राफ्ट अनुवाद — नेपाली समीक्षा बाँकी (`needs-nepali-review`)। मूल अङ्ग्रेजी: `docs/en/grade-10/m02-fork-clone-branch/lesson.md`। आदेश र कोड अङ्ग्रेजीमै।

**मुख्य विचार:** **branch** = एउटै रिपोभित्रको लेबल; **clone** = आफ्नो कम्प्युटरको प्रतिलिपि; **fork** = अरूको रिपोको सर्भरमा आफ्नै प्रतिलिपि।

## सार
```bash
git clone <your-fork-url>
git remote add upstream <original-url>
git switch -c feature/about-page
```
लेख्न नमिल्ने रिपोमा योगदान गर्न fork चाहिन्छ।
