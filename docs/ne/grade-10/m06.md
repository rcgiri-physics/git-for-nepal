# कक्षा १० · ट्याग र रिलिज

> ड्राफ्ट अनुवाद — नेपाली समीक्षा बाँकी (`needs-nepali-review`)। मूल अङ्ग्रेजी: `docs/en/grade-10/m06-releases/lesson.md`। आदेश र कोड अङ्ग्रेजीमै।

**मुख्य विचार:** ट्याग (`v1.0`) भनेको कमिटको स्थायी नाम; रिलिज = ट्याग + के बदलियो भन्ने नोट।

## सार
```bash
git tag -a v1.0 -m "First public version"
git push origin v1.0
```
नयाँ commit गर्दा ट्याग सर्दैन। `CHANGELOG.md` मा तीन बुँदा लेख्नुहोस्।
