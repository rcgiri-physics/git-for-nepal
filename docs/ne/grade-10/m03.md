# कक्षा १० · Pull request

> ड्राफ्ट अनुवाद — नेपाली समीक्षा बाँकी (`needs-nepali-review`)। मूल अङ्ग्रेजी: `docs/en/grade-10/m03-pull-requests/lesson.md`। आदेश र कोड अङ्ग्रेजीमै।

**मुख्य विचार:** PR भनेको "मेरो शाखा मिलाइदिनुहोस्; के र किन यहाँ छ; कृपया समीक्षा गर्नुहोस्" भन्ने अनुरोध हो।

## सार
शाखामा २–३ commit गरेर push गर्नुहोस्; PR खोल्नुहोस् (शीर्षक, विवरण, `Closes #1`, कसरी जाँच्ने)। समीक्षकले परिवर्तन गरिएका फाइल (diff) हेर्छ; थप सुधार उही शाखामा push गर्नुहोस्।

## निकास टिकट
1. `Closes #1` ले के गर्छ?
2. आफैँ मर्ज नगरी PR किन खोल्ने?
3. *भ्रम:* "PR नयाँ प्रतिलिपि हो।" (गलत)
