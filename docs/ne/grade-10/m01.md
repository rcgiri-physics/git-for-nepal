# कक्षा १० · Issue — कामको सूची

> ड्राफ्ट अनुवाद — नेपाली समीक्षा बाँकी (`needs-nepali-review`)। मूल अङ्ग्रेजी: `docs/en/grade-10/m01-issues/lesson.md`। आदेश र कोड अङ्ग्रेजीमै।

**मुख्य विचार:** Issue भनेको सबैले देख्ने ठाउँमा लेखिएको काम हो।

## सार
राम्रो issue = क्रियाले सुरु हुने छोटो शीर्षक + के/किन + कसरी थाहा पाउने कि सकियो। कागजको kanban भित्ता (गर्नुपर्ने / गर्दै / सकियो) बाट सुरु गर्नुहोस्; लेबल (`bug`, `feature`, `docs`) र जिम्मेवार तोक्नुहोस्।

## निकास टिकट
1. राम्रो issue का तीन भाग के हुन्?
2. issue कसलाई तोक्ने?
3. *भ्रम:* "issue बग मात्र हुन्।" (गलत)
