# कक्षा ८ · मोड्युल ३ — मेरो पहिलो रिपो

> ड्राफ्ट अनुवाद — नेपाली समीक्षा बाँकी। मूल: `docs/en/grade-08/m03-first-repo/lesson.md`

## तीन ठाउँ
```
मेरा फाइल        अर्को स्न्यापसटको बाकस      इतिहास
(कार्य प्रतिलिपि) -> (staging area)       -> (commits)
   सम्पादन            add                    commit
```
- **सम्पादन:** फाइल बदल्नु। **add:** परिवर्तनलाई अर्को तस्बिरको बाकसमा राख्नु। **commit:** तस्बिर खिचेर सन्देश लेख्नु।

## अभ्यास (जोडीमा: चालक र नेविगेटर)
१. VS Code को Source Control खोल्नुहोस्। २. `article.md` को शीर्षक बदल्नुहोस्; *के देखिन्छ अनुमान गर्नुहोस्*। ३. फाइल stage गर्नुहोस् (**+**), सन्देश लेखेर commit गर्नुहोस्। ४. वाक्य थपेर तीन कमिट पुर्‍याउनुहोस्।

## निकास टिकट
१. "अर्को स्न्यापसटको बाकस" लाई के भनिन्छ? २. फाइल बदलिएको तर commit नगरिएको किन हुन सक्छ? ३. *भ्रम:* "एडिटरमा save गरेपछि Git को इतिहासमा पर्छ।" (गलत)
