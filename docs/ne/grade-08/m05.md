# कक्षा ८ · मोड्युल ५ — पूर्ववत् र पुनःस्थापना

> ड्राफ्ट अनुवाद — नेपाली समीक्षा बाँकी। मूल: `docs/en/grade-08/m05-undo-restore/lesson.md`

## कार्डमा तीन अवस्था
१. अन्तिम कार्डपछि बिगारेँ → बिगारेको पाना फाल्ने, अन्तिम कार्डबाट फेरि सार्ने (**restore**)।
२. कार्ड c4 गलत थियो → पुरानो कार्ड नमेटी c5 बनाएर c4 को असर फर्काउने (**revert**)।
३. मङ्गलबारको अनुच्छेद चाहियो → c2 बाट सार्ने।

## अभ्यास
- commit नगरेको परिवर्तन फाल्न: `git restore article.md` (डिफ पहिले हेर्नुहोस् — फालेको फर्कँदैन!)
- गलत commit फर्काउन: `git revert HEAD` — इतिहास रहन्छ, नयाँ commit थपिन्छ।

**सुरक्षा नियम:** commit गरिएको काम सुरक्षित हुन्छ; commit नगरेको restore पछि फर्कँदैन।

## निकास टिकट
१. commit नगरेको सम्पादन फाल्ने आदेश? २. `revert` ले खराब commit मेट्छ? ३. *भ्रम:* "commit गरेपछि गल्ती सच्याउन सकिँदैन।" (गलत)
