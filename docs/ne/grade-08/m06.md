# कक्षा ८ · मोड्युल ६ — तथ्याङ्क: मेरा commit को चार्ट

> ड्राफ्ट अनुवाद — नेपाली समीक्षा बाँकी। मूल: `docs/en/grade-08/m06-stats-commits/lesson.md`

रिपोको इतिहास पनि **तथ्याङ्क** हो। आवृत्ति तालिका र स्तम्भ चित्र बनाऔँ।

१. `git log --date=short --format=%ad` ले प्रत्येक commit को मिति दिन्छ (अथवा छापिएको `log-sample.txt`)।
२. मिति / ट्यालीचिह्न / आवृत्ति तालिका बनाउनुहोस्।
३. ग्राफ पेपरमा स्तम्भ चित्र: x-अक्षमा मिति, y-अक्षमा commit सङ्ख्या; शीर्षक, अक्ष नाम, स्केल।
४. बहुलक (mode) र औसत (mean) निकाल्नुहोस्।

नमूना: १०-०१ → २, १०-०२ → १, १०-०५ → २, १०-०७ → १; औसत = ६ ÷ ४ = १.५।

*छलफल:* धेरै commit = राम्रो काम हो? (होइन — सन्देश र सामग्रीको गुणस्तर महत्त्वपूर्ण।)
