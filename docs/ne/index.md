# नेपालका लागि Git

> **ड्राफ्ट — मूल नेपाली भाषा समीक्षक चाहिन्छ (`needs-nepali-review`).** यो अनुवाद सहायकले तयार पारेको हो; कक्षामा प्रयोग गर्नुअघि नेपाली भाषाका जानकारले जाँच्नुपर्छ। आदेश र कोड अङ्ग्रेजीमै रहन्छन्।

कक्षा ८–१२ का लागि खुला, अफलाइन-पहिलो Git (संस्करण नियन्त्रण) पाठ्यक्रम।

| कक्षा | अध्याय | मुख्य विचार |
|---|---|---|
| ८ | मेरो कामको टाइम मेसिन | हरेक फाइलको इतिहास हुन्छ |
| ९ | शाखा र साझेदारी | शाखाले समानान्तर काम गर्न दिन्छ; रिमोटले काम सार्छ |
| १० | टोलीको कार्यप्रवाह | टोलीलाई काम नठोकिने नियम चाहिन्छ |
| ११ | खुला-स्रोत योगदानकर्ता | अरूले पनि प्रयोग गर्ने सफ्टवेयर सुधार्न सकिन्छ |
| १२ | Git सँग इन्जिनियरिङ | व्यावसायिक टोलीले सुरक्षित र दोहोरिने गरी रिलिज गर्छन् |
