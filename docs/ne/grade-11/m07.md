# कक्षा ११ · सफ्टवेयर प्रक्रिया मोडेल र Git कार्यप्रवाह

> ड्राफ्ट अनुवाद — नेपाली समीक्षा बाँकी (`needs-nepali-review`)। मूल अङ्ग्रेजी: `docs/en/grade-11/m07-process-models/lesson.md`। आदेश र कोड अङ्ग्रेजीमै।

**मुख्य विचार:** वाटरफल (एक ठूलो रिलिज) र एजाइल (साना बारम्बार कदम) लाई branch, PR र ट्यागसँग जोड्न सकिन्छ।

## सार
backlog ↔ issues; increment ↔ release ट्याग; code review ↔ गुणस्तर द्वार। CDC कक्षा १२ को 'सफ्टवेयर विकास प्रक्रिया' एकाइको पूर्वाभ्यास; यो मोड्युल कक्षा १२ मा सार्न सकिन्छ।
