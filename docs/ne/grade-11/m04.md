# कक्षा ११ · तपाईंको पहिलो PR — यही पाठ्यक्रममा

> ड्राफ्ट अनुवाद — नेपाली समीक्षा बाँकी (`needs-nepali-review`)। मूल अङ्ग्रेजी: `docs/en/grade-11/m04-first-pr/lesson.md`। आदेश र कोड अङ्ग्रेजीमै।

**मुख्य विचार:** fork → clone → शाखा → परिवर्तन → push → PR; परिवर्तन सानो (typo, शब्दकोश, उदाहरण)।

## सार
```bash
git switch -c fix/typo-grade8
python tools/validate_frontmatter.py
git push origin fix/typo-grade8
```
समीक्षा टिप्पणीमा जवाफ दिएर सुधार push गर्नुहोस्। PR बन्द भयो भन्दैमा असफल होइन।
