# कक्षा ११ · rebase, stash, revert, reset

> ड्राफ्ट अनुवाद — नेपाली समीक्षा बाँकी (`needs-nepali-review`)। मूल अङ्ग्रेजी: `docs/en/grade-11/m05-rebase-stash-revert/lesson.md`। आदेश र कोड अङ्ग्रेजीमै।

**मुख्य विचार:** **स्वर्ण नियम:** अरूसँग भइसकेको इतिहास कहिल्यै नबदल्नुहोस्।

## सार
`stash` = अधुरो काम दराजमा; `revert` = शेयर भइसकेको खराब commit को असर उल्टाउने नयाँ commit; `reset` = push नभएको commit मात्र; `rebase` = आफ्नो commit नयाँ main माथि दोहोर्‍याउने। हराएको commit `git reflog` बाट भेटिन्छ। फाल्नु मिल्ने रिपोमा मात्र अभ्यास।

## निकास टिकट
1. push भएको शाखामा `reset` जोखिमपूर्ण किन?
2. `git reflog` ले के गर्छ?
3. *भ्रम:* "rebase र merge को इतिहास उस्तै हुन्छ।" (गलत)
