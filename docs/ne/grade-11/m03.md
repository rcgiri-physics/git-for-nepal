# कक्षा ११ · Triage: राम्रो पहिलो issue

> ड्राफ्ट अनुवाद — नेपाली समीक्षा बाँकी (`needs-nepali-review`)। मूल अङ्ग्रेजी: `docs/en/grade-11/m03-triage/lesson.md`। आदेश र कोड अङ्ग्रेजीमै।

**मुख्य विचार:** सानो, स्पष्ट, फाइलको सङ्केत भएको issue = 'good first issue'।

## सार
issue को आकार (S/M/L), स्पष्टता, चाहिने सीप मूल्याङ्कन गर्नुहोस्। सुरु गर्नुअघि टिप्पणी गर्नुहोस्: "के म यसमा काम गरूँ? मेरो योजना…" र अनुमतिको प्रतीक्षा गर्नुहोस्। कार्यक्रमका लागि मात्र PR पठाउने (स्प्याम) हुँदैन।

## निकास टिकट
1. 'good first' issue के हो?
2. सुरु गर्नुअघि किन टिप्पणी गर्ने?
3. *भ्रम:* "ठूला issue सधैँ राम्रा।" (गलत)
