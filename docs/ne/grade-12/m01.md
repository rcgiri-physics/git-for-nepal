# कक्षा १२ · Git भित्रबाट

> ड्राफ्ट अनुवाद — नेपाली समीक्षा बाँकी (`needs-nepali-review`)। मूल अङ्ग्रेजी: `docs/en/grade-12/m01-internals/lesson.md`। आदेश र कोड अङ्ग्रेजीमै।

**मुख्य विचार:** Git का चार वस्तु: **blob** (फाइलको सामग्री), **tree** (फोल्डर), **commit**, **tag**; सामग्रीको hash नै नाम हो।

## सार
```bash
git cat-file -t <hash>
git cat-file -p HEAD
cat .git/refs/heads/main
```
शाखा भनेको एउटा hash राखेको फाइल मात्र हो। commit ले tree र parent लाई औँल्याउँछ।
