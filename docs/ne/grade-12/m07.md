# कक्षा १२ · इतिहासमा डिबगिङ: blame र bisect

> ड्राफ्ट अनुवाद — नेपाली समीक्षा बाँकी (`needs-nepali-review`)। मूल अङ्ग्रेजी: `docs/en/grade-12/m07-blame-bisect/lesson.md`। आदेश र कोड अङ्ग्रेजीमै।

**मुख्य विचार:** `bisect` ले इतिहासमा द्वयी खोज गर्छ: ६४ commit मा करिब ६ परीक्षण।

## सार
```bash
git blame check.sh
git bisect start HEAD <old-commit>
git bisect run bash check.sh
git bisect reset
```
अभ्यास रिपो: `g12-capstone-starter` (`make-bisect-demo.sh`)। `blame` = 'कसलाई सोध्ने?', दोष देखाउने होइन।

## निकास टिकट
1. ६४ commit मा कति परीक्षण?
2. blame ले के देखाउँछ?
3. *भ्रम:* "blame सजाय दिन हो।" (गलत)
