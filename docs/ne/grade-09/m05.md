# कक्षा ९ · रिमोट: clone, push, pull

> ड्राफ्ट अनुवाद — नेपाली समीक्षा बाँकी (`needs-nepali-review`)। मूल अङ्ग्रेजी: `docs/en/grade-09/m05-remotes/lesson.md`। आदेश र कोड अङ्ग्रेजीमै।

**मुख्य विचार:** रिमोट भनेको भण्डारको अर्को प्रतिलिपि हो; `push` र `pull` नगरेसम्म केही सर्दैन।

## सार
```bash
git clone <url> ward-facts
git remote -v
git push origin main
git pull
```
**अफलाइन (तह १):** `git bundle create share.bundle --all` बनाएर USB मार्फत साट्नुहोस्; साथीले `git pull share.bundle main` चलाउँछ। **१३ वर्षमुनिका विद्यार्थीले GitHub खाता खोल्न पाउँदैनन्।**
