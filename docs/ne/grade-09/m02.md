# कक्षा ९ · CLI मा status, add, commit, log

> ड्राफ्ट अनुवाद — नेपाली समीक्षा बाँकी (`needs-nepali-review`)। मूल अङ्ग्रेजी: `docs/en/grade-09/m02-cli-basics/lesson.md`। आदेश र कोड अङ्ग्रेजीमै।

**मुख्य विचार:** कक्षा ८ मा क्लिक गरेका काम अब आदेशका रूपमा लेखिन्छन्।

## सार
```bash
git init ward-facts
git status
git add README.md
git commit -m "Add README"
git log --oneline
```
प्रत्येक आदेशअघि *के देखिन्छ अनुमान गर्नुहोस्*, अनि चलाउनुहोस्।

## निकास टिकट
1. `git status` ले के भन्छ?
2. `git diff` र `git diff --staged` मा के फरक?
3. *भ्रम:* "git add ले इतिहासमा सुरक्षित गर्छ।" (गलत)
