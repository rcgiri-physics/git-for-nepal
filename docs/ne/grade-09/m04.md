## सार
```bash
git switch main
git merge add-verse
```
द्वन्द्व भए फाइलमा `<<<<<<<`, `=======`, `>>>>>>>` देखिन्छ: अन्तिम पाठ रोज्नुहोस्, चिह्न हटाउनुहोस्, `git add`, `git commit`। `git merge --abort` ले मर्जअघि फर्काउँछ।
