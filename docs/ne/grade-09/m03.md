**मुख्य विचार:** शाखा भनेको कमिटमा टाँसिएको सार्न मिल्ने स्टिकी नोट हो — फोल्डरको पूरा प्रतिलिपि होइन।

## सार
```bash
git branch
git switch -c add-verse
git switch main
```
शाखा बदल्दा नयाँ फाइल हराउँछ — किनभने त्यो अर्को शाखामा छ।
