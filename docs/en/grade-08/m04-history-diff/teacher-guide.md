# Teacher guide — Module 4 (2 periods)

**Timing:** P1: hook 5, unplugged 15, lab 1–2 (20). P2: lab 3–5 (25), Parsons 10, exit 5.

## Common errors
- `git log` opens a pager and the student is stuck: press **q** to quit.
- Colour-blind students: also teach the `+` and `-` signs at the start of lines; the unplugged activity can use "circle" and "underline".
- Mixing up `git diff` (uncommitted) and `git show` (a commit).

## Fallbacks
- Tier 0: print the two versions of `article.md` (commit 2 and commit 5) and the log from the practice repo; run the whole lesson on paper.
- One computer: project it; pairs answer on paper.

## Answer key
Exit 1: red/`-` removed, green/`+` added. 2: author, date/time, message, parent commit (any two). 3: false.
Parsons: `git log --oneline` list history · `git show` commit changes · `git diff` uncommitted changes.

## Extension quest
Find the commit where a word was misspelled and when it was fixed.
