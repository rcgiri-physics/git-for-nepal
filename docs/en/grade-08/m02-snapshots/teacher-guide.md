# Teacher guide — Module 2 (2 periods)

**Timing:** Period 1: hook 5, paper commits 25, reflect 10. Period 2: predict 10, Parsons 10, swap activity 15, exit 5.
**Materials:** 8 index cards per pair, string or lines drawn with pen, pens.

## Common errors
- "Commit = copy of only the changed line." Correct: in the game each card holds the *whole* sheet — Git stores a snapshot of the project and cleverly shares unchanged parts.
- Vague messages ("done", "ok"). Use the swap activity to show why they hurt.
- Students forget to write the parent. Insist on the string.

## Fallbacks
Fully unplugged. With no cards, use half sheets of paper.

## Answer key
- Parsons: Write title → Add first verse → Fix spelling → Add second verse (any order consistent with the card messages is fine if the student justifies it).
- Exit 1: a saved snapshot of the project with a message. 2: e.g. "Add heading to the essay". 3: False.

## Extension quest
Make the cards for a *wrong* edit and add a new commit that fixes it, instead of rubbing out an old card. (History is never rewritten here — prepares Module 5.)
