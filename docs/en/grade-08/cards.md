# Printable cards (Grade 8)

Print on A4, cut along the lines. Black-and-white friendly.

## Paper-commit card (print 8 per pair)
```
+--------------------------------------------+
| Commit no.: c___        parent: c___       |
| Message (what + why):                      |
| ________________________________________   |
|                                            |
| Copy of the whole sheet goes here:         |
|                                            |
|                                            |
+--------------------------------------------+
```

## Parsons cards — Module 3 (cut each line into a strip, shuffle, order)
- edit the file
- git add article.md
- git commit -m "Change title"
- git status says "nothing to commit"

## Parsons cards — Module 5
- notice the mistake
- look at git log
- git revert HEAD
- check the log again
- write why in the message

## Badges (record in your own `BADGES.md`; no leaderboards)
| Badge | Earned when |
|---|---|
| First Snapshot | made your first commit |
| Time Traveller | restored an old version |
| Spot the Difference | explained a diff aloud |
| Historian | five meaningful commits |
