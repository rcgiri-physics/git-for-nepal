# Git for Nepal

Open, offline-first lessons on **Git and version control** for Grades 8–12.

!!! warning "v0.1 prototype"
    Grade 8 is a full chapter. Grades 9–12 are core lessons that have **not yet been tried in a classroom**. The mapping to CDC units is a draft until the official syllabi are checked.

| Grade | Chapter | Big idea |
|---|---|---|
| [8](grade-08/index.md) | Time Machine for My Work | every file has a history |
| [9](grade-09/index.md) | Branch and Share | branches work in parallel; remotes let work travel |
| [10](grade-10/index.md) | Team Workflows | teams need rules so work does not collide |
| [11](grade-11/index.md) | Open-Source Contributor | you can improve software others also use |
| [12](grade-12/index.md) | Engineering with Git | professional teams ship safely, repeatedly |

## For teachers
