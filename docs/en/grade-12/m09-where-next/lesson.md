# 9. Where Git goes next

## Hook
Most people learn Git as an extra. Where does it actually take you?

## Concept (unplugged or visual first)
Short talks and a one-page **pathway map**:
- **University:** CS/IT/engineering courses use Git for assignments and labs.
- **Industry:** DevOps, code review, CI/CD, infrastructure as code.
- **Research:** reproducible analyses; data and code versioned together.
- **Writing:** documentation-as-code, Markdown, translations.
- **Data/ML:** versioning datasets and experiments.
- **Open source:** mentoring programmes. Google Summer of Code and Outreachy both require applicants to be **18 or older** (checked October 2026; GSoC also requires student or open-source-beginner status), so many Grade 12 students will become eligible only after school. Rules change yearly: re-check before you teach this. The GitHub Student Developer Pack was not checked.

## PRIMM lab
1. Interview an adult who uses version control (teacher, alumnus) or watch a recorded talk (guest-talk template: 5 min what I do · 5 min a story where history saved me · 10 min Q&A).
2. **Predict** which of your interests connect to Git.
3. Fill the pathway map: *now → next year → after school*, with one concrete step each.
4. **Make:** publish your map in your portfolio repo.

## Parsons practice
Match field → Git use: research → reproducibility; industry → CI/CD; writing → documentation as code.

## Exit ticket
1. Name two fields where Git is used.
2. What is your next concrete step?
3. *Misconception:* 'Git is only for programmers.'
