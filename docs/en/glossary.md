# Glossary

| Word | नेपाली | Meaning |
|---|---|---|
| repository (repo) | भण्डार | a project folder that remembers its history |
| commit | कमिट / स्न्यापसट | a saved snapshot with a message |
| history / log | इतिहास | the list of commits |
| diff | फरक | the difference between two versions |
| branch | शाखा | a movable label pointing at a commit |
| merge | मिलाउनु | combine the work of two branches |
| conflict | द्वन्द्व | two changes to the same lines that Git cannot combine alone |
| remote | टाढाको भण्डार | a copy of the repo on another computer or server |
| clone | क्लोन | copy a whole repo with its history |
| push / pull | पठाउनु / ल्याउनु | send / receive commits to / from a remote |
| fork | फोर्क | your own copy of someone else's repo on a server |
| pull request (PR) | | a request to merge your branch, with a place to discuss it |
| issue | | a task, bug or idea written down on the server |
| tag / release | | a named, fixed version such as v1.0 |
| staging area (index) | | the "next snapshot" you are preparing |
