# Teacher training: 3-hour introduction

**Audience:** computer teachers with no Git background. **Needs:** one computer per two teachers (or none: Part 1 is paper).

| Time | Part | Activity |
|---|---|---|
| 0:00–0:15 | Why | Show a folder with `report_final_final_v3_real.doc`. Ask: "which one is the right one?" Discuss. |
| 0:15–0:45 | Paper commits | Run Grade 8 Module 2 exactly as students would: index cards = commits, string = history. |
| 0:45–1:00 | Break | |
| 1:00–1:45 | First repo | Install Git (USB kit, tier 1). Make a repo, commit three times, read `git log`. |
| 1:45–2:15 | Undo and compare | `git diff`, `git restore`, `git revert`. Explain the three most common mistakes. |
| 2:15–2:40 | Your classroom | Plan: which tier you have, how many pairs, which module first. Read one teacher guide together. |
| 2:40–3:00 | Exit | Each teacher writes one thing they will try and one worry. Collect (anonymously) for the maintainers. |

## Trainer notes
- Let teachers be confused with the *model* first; commands come after.
- Show that mistakes are recoverable: deliberately delete a file and bring it back.
- Hand out the printed Module 1 teacher guide and a Parsons card set.

## Follow-up (2-day workshop kit — outline)
Day 1: Grade 8–9 labs end to end. Day 2: set up a LAN Forgejo or GitHub class organisation; plan the pilot; practise giving feedback on commit messages.
