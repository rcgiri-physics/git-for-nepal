# Pilot 1 protocol (Grade 8)

**Goal:** find out whether a teacher with no Git background can teach the Grade 8 chapter, and whether students grasp "history, snapshot, restore".

## Sites (recruit 3–5; name them here only with consent)
| Type | Tier | Why |
|---|---|---|
| Urban, internet | 3 | baseline |
| Community school with LAN/lab | 1–2 | typical |
| Rural, one PC | 0–1 | hardest case |

## Instruments (no PII — use codes `S01…`)
1. **Pre/post concept quiz** — the 10 items in `assessments/g08-pilot-quiz.md`; same items before and after.
2. **Teacher survey** — time per module vs plan, where the guide failed, fallback used, confidence (1–5) before/after.
3. **Observation notes** — one observer per site, using the checklist below.
4. **Student feedback** — 3 emoji-scale questions + 1 free sentence; anonymous.

## Observation checklist (per module)
- [ ] Did the hook land (students could explain the problem)?
- [ ] Time overrun by module part (hook / concept / lab / Parsons / exit)?
- [ ] Which misconception from the teacher notes appeared? Any new one?
- [ ] Was pair work possible with the available computers?
- [ ] Which words needed Nepali glosses?

## Reporting
Write `research/pilot-01.md`: sites (types only), n, quiz mean pre/post, teacher quotes (anonymised), top 5 changes made. Merge the revisions **before** starting Grade 9 production.

## Ethics
Parent/school consent per local rules; no photos or names; results reported in aggregate.
