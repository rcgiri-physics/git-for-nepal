# Governance

## Roles
| Role | Responsibility |
|---|---|
| Maintainer | merges, releases, final say on scope *(currently: the repository owner)* |
| Pedagogy reviewer | checks lessons follow the module template and PRIMM structure |
| Nepali-language reviewer | approves all `docs/ne/` text |
| Technical reviewer | runs commands and practice repos end-to-end |
| Teacher reviewer | confirms a lesson is teachable in the time and with the tier fallbacks stated |

A new module needs ≥ 2 approvals, one of them a teacher.

## Scope guard
Each grade has fixed outcomes (see the chapter `index.md`). Extra content is labelled **optional/enrichment**. Proposals to add outcomes go through an issue first.

## Releases
Quarterly. `v0.1` Grade 8 · `v0.2` Grade 9 · `v0.3` Grade 10 · `v0.4` Grade 11 · `v0.5` Grade 12 · `v1.0` after pilot-driven revision. Changes recorded in `CHANGELOG.md`. A yearly "curriculum review" issue checks tool versions and links.

## Decisions
Open decisions live in `research/decisions.md`. A decision is closed by a PR that changes that file.
