# Grade 8 pilot quiz (10 items; same items pre and post)

Use student codes (S01…), never names. 1 mark each.

1. Why can `final_final_v3.doc` be confusing? (a) no record of what changed (b) files are too big (c) it is illegal (d) none
2. A commit is… (a) a deleted file (b) a saved snapshot with a message (c) a copy of the internet (d) a password
3. True/False: Saving a file in your editor adds it to Git's history.
4. A diff shows… (a) the differences between versions (b) the biggest file (c) your marks (d) the internet speed
5. Which is the better message? (a) "stuff" (b) "Add heading and fix spelling of Bhaktapur"
6. You deleted a paragraph but have NOT committed. How can you get it back? (a) restore from the last commit (b) impossible (c) buy a new PC
7. True/False: `revert` erases the bad commit from history.
8. Which comes first: `add` or `commit`?
9. True/False: Commits can be used as data for a bar chart.
10. In one sentence, explain what version history is for.

Answers: 1a · 2b · 3F · 4a · 5b · 6a · 7F · 8 add · 9T · 10 free text (score 1 if it mentions going back/seeing what changed/why).
